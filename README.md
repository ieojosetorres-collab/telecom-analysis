# 📡 Telecom Analysis

Data Analytics project focused on customer behavior analysis for **ConnectaTel**, a telecommunications company in Latin America.

## 📌 Project Overview

This project analyzes customer usage patterns using three datasets:

- **plans.csv:** Current service plans (pricing, included minutes, data allowance, extra usage costs).
- **users_latam.csv:** Customer information (age, city, registration date, plan, churn).
- **usage.csv:** Historical records of calls and text messages.

## 🎯 Objectives

- Perform data cleaning and preprocessing.
- Handle missing values and sentinel values.
- Explore customer behavior through descriptive statistics.
- Detect and analyze outliers.
- Segment customers by age and usage level.
- Generate visualizations to identify consumption patterns.
- Provide executive insights and business recommendations.

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📈 Key Analyses

- Data quality assessment
- Summary statistics
- Histograms and boxplots
- Outlier detection using the IQR method
- Customer segmentation
- Executive business insights
